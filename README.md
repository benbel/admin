# Organisation de l'administration centrale

Ministères et services de l'État d'après [l'annuaire de l'administration](https://lannuaire.service-public.gouv.fr/navigation/ministeres), avec des réorganisations possibles : création, renommage, rattachement, fusion, scission, suppression.

Les modifications sont enregistrées dans l'adresse de la page, qui peut être partagée.

```
python -m admin.collecte     # met à jour site/services.json
python -m http.server -d site
```
